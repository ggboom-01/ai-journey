# AI 学习资源清单（2026 · 免费为主）

> 配套《AI 学习与就业路线图（2026 版）》使用。
> 核心心法：**一流资源几乎全在 GitHub、Datawhale、Hugging Face 和 DeepLearning.AI 上，不必花钱。**

---

## 怎么挑教程：「三要三不要」

✅ 要官方 / 一手信源（生态维护者出的，更新最及时）
✅ 要能动手跑代码（支持 Jupyter Notebook / Colab 一键运行）
✅ 要贴近工程落地（讲清楚错误重试、状态保持、多步骤流转）

❌ 不要纯 PPT 概念速成课（看懂了名词，依然写不出一行代码）
❌ 不要过时的简单套壳课（只会调一次对话 API 绝不等于 Agent）
❌ 不要焦虑式付费圈子

## 一、中文主线（强烈推荐首选）

### 2. 视频课（中文）

- **李宏毅（台湾大学）《生成式 AI》《AI Agent 系统设计》** —— 最好懂的中文视听课。用漫威、哈利波特类比讲多智能体协作和工具调用，B 站有搬运。适合通勤时当高质量播客刷，建立大局观。
- **李沐《动手学深度学习》d2l.ai + 论文精读系列** —— 原理与实现并重，中文深度学习的标杆。
- **李沐论文精读** —— 想读前沿论文的话，从这里入门不会迷路。

### 3. 开源书

- **《动手学大模型智能体》**（上海交大团队）—— 靠谱的中文体系化著作，配套大量开箱即用的 Notebook，从环境搭建到部署一步到位。

## 六、学习节奏建议

1. **不要贪多**：选一条路线，坚持学完，比东学一点西学一点效果好得多。
2. **动手实践**：每个课程都有配套代码 / 作业，一定要亲手做。
3. **先跑通再理解**：fast.ai 的理念——先让模型跑起来，再深入原理。
4. **加入社区**：Datawhale、Kaggle、Hugging Face 都有活跃讨论。
5. **学以致用**：学完一个模块，立即用到自己的项目里。
6. **不要屯课**：遇到具体概念不理解（比如「什么是向量数据库」），就去找对应的 20 分钟视频，搞懂就关掉，继续干活。
