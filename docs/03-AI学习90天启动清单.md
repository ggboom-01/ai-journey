# AI 学习 90 天启动清单（可打勾）

> 配套《AI 学习与就业路线图（2026版）》使用。
> 用法：不要通读。**从今天这一周开始，做完一项划掉一项。** 90 天结束时你应该有一个能拿出去给面试官看的作品。

---

## 开始前的三个约定

- [ ] 每天固定时段学习（建议 1.5～2 小时），写进日历，不要靠「有空就学」
- [ ] 建一个 GitHub 仓库 `ai-journey`，**每天/每周提交一次**，学习痕迹本身就是作品
- [ ] 定一个「作品目标」：90 天后要交付 1 个完整项目（建议：私有知识库问答 Agent）

---

## 第 1 周 · 环境与第一口氧气

- [ ] 装好 Python 3.12+、VS Code、Git，能跑通 `python --version` 和 `git --version`
- [ ] 注册 GitHub、Hugging Face、ModelScope 账号
- [ ] 用 Ollama 在本地跑起一个开源小模型，成功对话一次
- [ ] **动手**：跟着 Hugging Face Agents Course 的 Unit 1，在 Colab 上跑通你的第一个智能体
- [ ] 写下第一篇学习笔记，提交到 `ai-journey`

> ✅ 本周末成果：本地跑通模型 + 云端跑通第一个 Agent。

## 第 2–3 周 · Python 工程能力

- [ ] 复习 Python 进阶：类型注解、`asyncio`、异常处理、`dataclass`
- [ ] 学会 `requests` / `httpx` 调 HTTP 接口，理解 JSON
- [ ] 用 **FastAPI** 写一个接口，实现「输入问题 → 调用大模型 → 返回答案」
- [ ] 学会用 **Pydantic** 做数据校验和结构化输出
- [ ] 学会 Git 基本操作：add / commit / branch / push / PR

> ✅ 成果：一个可通过 HTTP 调用的 AI 问答接口（第 1 个可展示项目）。

## 第 4 周 · 大模型 API 与 Prompt 工程

- [ ] 通读一家模型厂商的 API 文档（从第一页看到最后一页）
- [ ] 对比调用至少两家模型（如 DeepSeek / Qwen / GPT / Claude），写一篇对比笔记
- [ ] 掌握：系统提示词、Few-shot、思维链 CoT、结构化输出（JSON）
- [ ] 掌握流式响应（streaming）的实现
- [ ] 建一个自己的 Prompt 模板库（按任务分类，带版本）

> ✅ 成果：3 个不同场景的 LLM 应用 + 个人 Prompt 模板库。
> ⚠️ 提醒：**第 4 周必须开始写项目，不要等课程全部看完。**

## 第 5–6 周 · RAG 入门（关键期）

- [ ] 理解：为什么需要 RAG？RAG 与微调的区别是什么？
- [ ] 动手：文档加载 → 切片（chunk）→ Embedding → 存入向量库
- [ ] 跑通一个最小 RAG 问答（用 LangChain 或 LlamaIndex，或纯手写）
- [ ] 认识三个向量库：FAISS（本地小规模）、Chroma（轻量）、Milvus（生产）
- [ ] 了解 Embedding 模型选型：BGE-M3、GTE 系列
- [ ] 做一次切块实验：不同 chunk size / overlap 对检索结果的影响，记录数据

> ✅ 成果：一个能回答你自己文档问题的知识库助手 v1。

## 第 7–8 周 · RAG 进阶 + 评估

- [ ] 加**混合检索**：向量检索 + BM25 关键词检索
- [ ] 加 **Reranker 重排序**
- [ ] 加**引用溯源**：回答里标出原文出处
- [ ] 加**元数据过滤**（按文档类型 / 时间 / 权限筛选）
- [ ] 引入评估：用 RAGAS 或自建评估集，量化「检索命中率」和「回答准确率」
- [ ] 处理幻觉：提示词约束 + 输出后校验
- [ ] 用 Streamlit / Gradio 做一个能给别人看的界面

> ✅ 成果：生产级知识库助手（含引用、评估、界面）—— **这是你作品集里的第一个硬货。**

## 第 9–10 周 · Agent 工程

- [ ] 吃透 **Function Calling**：工具 JSON Schema → 结构化调用 → 执行 → 结果回填
- [ ] 手写一个完整 **ReAct 循环**（Thought → Action → Observation）
- [ ] 学 **LangGraph**：状态机、条件分支、循环、状态持久化
- [ ] 加**记忆机制**：短期上下文窗口管理 + 长期存储
- [ ] 加**失败处理**：最大步数限制、重复动作检测、超时控制（防死循环三板斧）
- [ ] 接入 **MCP**，让 Agent 能连外部工具
- [ ] 了解 A2A（Agent 间协作）与 AG-UI 协议
- [ ] 做一个**多步真实任务**的 Agent，并在关键动作前加人工确认

> ✅ 成果：一个能自主完成多步任务的 Agent（第 2 个可展示项目）。

## 第 11–12 周 · 生产化与作品集包装

- [ ] Docker 打包你的应用，docker-compose 一键起
- [ ] 部署到云端（阿里云 / 腾讯云 / 海外 VPS 均可），拿到公网可访问的地址
- [ ] 接入可观测性：Langfuse 或 LangSmith，能看到每次调用的链路和 Token 消耗
- [ ] 做成本核算：单次问答多少钱？QPS 上去之后怎么办？
- [ ] 写一份模型对比评估：准确率 / 延迟 / 成本 / 幻觉率（第 3 个项目）
- [ ] **把项目写成工程案例**：问题背景、架构图、选型理由、评估方法、失败模式、成本、Demo 链接
- [ ] 写一份 README + 一段 3 分钟的项目讲解视频

> ✅ 成果：**1 个旗舰项目 + 1 个评估项目 + 2 个基础项目**，全部可展示。

- [ ] 有一个 200+ commits 的 GitHub 仓库

- [ ] 有 1 个公网可访问的 Demo

## 如果中途卡住了

| 症状 | 处方 |
|---|---|
| 环境配了三天还没配好 | 直接用 Colab / 云端 notebook，先把代码跑通，本地环境后面再补 |
| 概念看不懂 | 别死磕。按「先跑通再理解」来，跑三遍自然就懂了 |
| 视频课看不下去 | 换教程。中文看不下去就换李宏毅，英文的换 Hugging Face 交互式 notebook |
| 卡在某一步超过 2 小时 | 去 Datawhale 社群 / GitHub Issues 提问，别自己硬耗 |
| 想换方向 | 回忆路线图第二节：**先走完第二梯队，不要中途跳去算法研发** |
| 觉得自己学得太慢 | 每周 10 小时、6～9 个月能到可面试水平，这是正常速度。慢的是不动手的人 |
