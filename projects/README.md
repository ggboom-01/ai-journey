## 判断一个项目值不值得放进来

问自己三个问题：

1. 它能证明我理解**真实的 AI 工程问题**吗？
2. 我能讲清楚**架构、选型和 trade-off** 吗？
3. 它和「套壳聊天机器人」的区别是什么？

三个问题有一个答不上来，就还不是作品集级别的项目。

## 反面清单（不要放）

- ❌ 跟着教程敲的聊天机器人
- ❌ 只有源码没有 README
- ❌ README 里写不出「踩过什么坑」
- ❌ 没有评估数据、只有感觉「效果不错」
- ❌ 提交了 API Key（这条一旦发生，需要立刻作废密钥并清理历史）
